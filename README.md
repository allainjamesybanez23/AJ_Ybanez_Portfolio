Portfolio of Allain James O. Ybañez, a B.S. Computer Science student majoring in AI and Web Development at the University of San Jose-Recoletos, Cebu, looking for an OJT practicum starting January 2027 (324 hours).

Live site: https://allainjamesybanez23.github.io/AJ_Ybanez_Portfolio/

The layout follows the Sawad Framer portfolio style (dark page, sticky profile card, big two-tone headings, floating section nav) in the site's green and gold colors. Every project is shown open, so nothing needs to be clicked to read it.

It is a single page with no build step: `index.html` plus the `images` and `videos` folders and the CV PDF.
